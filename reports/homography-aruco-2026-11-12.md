## 구성 및 수정

- `edge-vision/`: 도구·설정·진단·웹 송신·테스트를 웹 서버와 분리.
- `.vercelignore`: 카메라 PC 코드와 대형 로컬 모델 폴더를 Vercel 패키징에서 제외.
- 원본의 사용하지 않는 전체 AI 설정은 `reference/configs/`에 보존하고 최소 설정을 사용.
- 실행용 보정 템플릿은 미보정 상태. 유효하지 않은 원본 행렬을 재사용하지 않음.
- 런타임에도 사각형의 순서·볼록성·중복·화면 경계 검증 적용.
- Pillow 누락 시 오버레이의 ASCII 대체 표시가 실제로 동작하도록 수정.
- 측정되지 않은 헤딩을 정상 보드 위치로 송신하지 않도록 차단.
- 웹 서비스 인증, 단위·좌표·순서·세션 검사, 최신 1개 저장, 시각 진단 API 추가.
- 기존 익수 판정 경로와 위치 관측을 분리하고 기존 이미지 접수 시간 제한을 유지.
