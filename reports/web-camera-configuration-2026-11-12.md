# 웹 호모그래피·ArUco 설정 통합

## 기존 원인

웹 카메라 스트림은 미보정 `Calibration({})`와 고정 ArUco 설정으로 생성됐습니다.
로컬 도구 `edge-vision/`의 설정은 웹 추적 서비스에 자동 반영되지 않았으며,
Vercel에서는 기존 로컬 `/api/calibration` 경로도 등록하지 않습니다.

## 구현

- 설정 화면에 호모그래피와 ArUco를 각각 별도 카드·저장 API로 제공.
- 호모그래피는 연결 중인 카메라의 실시간 영상에서 4점을 지정·드래그하고
  실측 수조 너비·높이 및 좌표계 이름을 입력. ROI 설정과 분리.
- ArUco는 사전·ID·실측 마커 크기·실측 헤딩 오프셋·측정 확인을 독립 저장.
- 마커 PNG 생성과 저장된 설정으로 현재 카메라 프레임 검사 지원.
- 설정은 PostgreSQL `camera_configurations`에 사이트·카메라별 JSON과 버전으로 저장.
  저장 권한은 관리자, 조회·영상 확인은 운영자/관리자. 원본 이미지는 DB에 저장하지 않음.
- 새 스트림에 Vercel이 저장된 설정을 전달하고 CPU 추적 서비스의 버전 확인 응답을 검증.
  다른 버전/미지원 서버는 정상 적용으로 표시하지 않음.
- 설정 변경 시 같은 카메라 MediaStream을 유지하고 추적 세션만 재시작.
  대상 ID와 15프레임 판정은 새 세션 기준으로 다시 누적.
- 호모그래피 점은 원본 영상 백분율로 저장하여 분석 이미지 축소에 맞춰 변환.
  영상 비율이 1% 넘게 바뀌면 실좌표 변환을 거부.
- ArUco는 호모그래피 없이도 검출. 미터 좌표에는 호모그래피,
  선수 헤딩에는 실측 오프셋 확인이 각각 필요.
- 분석 프레임에 마커 테두리와 ID, 사용 가능한 실좌표·헤딩을 표시.
  익수 분석 대상의 bbox 기준점도 저장한 호모그래피로 미터 좌표 변환.
- 기존 RF-DETR/Moondream 모델, 0.8/15프레임 판정 규칙과 프레임/포즈 유효시간은 유지.
  좌표가 있어도 실제 보트 브릿지가 없으면 출동을 승인하지 않음.

## 검증

- 새 웹 설정 API 테스트 5개 통과: 권한, 독립 저장·보존, 잘못된 점·ID,
  스트림 설정 전달·버전 확인, 이미지 진단 프록시.
- CPU 런타임 통합 테스트 3개 통과: 실제 OpenCV 검출, 축소 영상 실좌표,
  헤딩 미측정 차단, 설정 스트림·마커 PNG·영상 검사.
- JS 설정 테스트: 4점 입력, 독립 저장 시 다른 편집 보존, 설정 버전, 마커 PNG,
  프레임 검사 및 같은 MediaStream 재사용 통과.
- 기존 카메라 테스트에 설정 변경 후 카메라 유지·추적 재생성 검증 추가.
- 기존 ROI·edge 화면·추적 오류 진단·통합 서버 및 15프레임 gate 회귀 검증 통과.
- Chrome에서 두 설정 카드의 표시·4점 지정·별도 저장·미디어 공유 확인 (합성 영상/모의 저장 API).
- Modal CPU 서비스 배포 후 실제 API로 독립 호모그래피, 독립 ArUco, 동시 사용 및
  설정 버전 777의 임시 스트림 생성·삭제 확인. 실제 사이트 설정은 변경하지 않음.
- 합성 마커 측정: X=0.399609 m, Y=0.400694 m, 헤딩=105도. 실제 수조의 측정 정확도가 아님.

현장 카메라 보정점, 수조 크기, 마커 인쇄 크기, 선수 오프셋은 사용자가 실측해야 합니다.
분석 프레임의 과거 좌표는 현재 제어 가능한 보트 위치를 의미하지 않습니다.
실물 주행·출동·복귀·완료는 이번 검증에 포함하지 않았습니다.
