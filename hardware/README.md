# 보드 연결

웹에서 만든 명령을 실제 보드에 전달하는 프로그램입니다.
웹 서버나 AI 모델을 실행하는 폴더가 아닙니다.

| 파일 | 연결 방식 | 웹 경로 |
| --- | --- | --- |
| `bridges/usb_bridge.py` | Windows USB, 현재 COM3 / 9600 | `/api/board-control` |
| `bridges/hc06_bridge.py` | HC-06 블루투스 직렬 포트 | `/api/test-control` |
| `requirements.txt` | 두 브릿지에 필요한 패키지 목록 | — |

두 브릿지는 사용하는 명령 경로가 다릅니다. 연결 방식에 맞는 프로그램 하나를 실행하세요.
웹 관제의 신호 패널에서도 같은 연결 방식을 선택합니다.

설치·실행 순서는 [보드 연결 안내](../docs/보드연결.md)를 참고하세요.
