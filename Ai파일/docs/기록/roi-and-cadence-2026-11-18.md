# ROI 필터와 분석 갱신 간격 검증

2026-11-18. 보드 명령을 보내거나 사이트 설정을 바꾸지 않고 검증했습니다.

기존 문제는 저장 ROI가 추적 서버로 전달되지 않아 화면 표시와 실제 분석 영역이 달랐던 것입니다. 현재 모델 입력의 ROI 밖 마스킹, 상자 중심점 기반 필터, 현재 ROI에 대한 출동 증거 재검증이 적용돼 있습니다. 경계 위는 포함하며, 보드 ArUco는 원본 영상에서 독립 검출합니다.

모델 상태 확인 후 측정한 단기 샘플이며, 실제 웹캠의 캡처·인코딩 시간이나 다양한 네트워크·장시간 안정성을 검증한 것은 아닙니다. 첫 프레임 이후 약 0.27~0.29fps이고 연속 영상 수준의 실시간 분석을 달성한 것은 아닙니다. 15개 연속 분석 증거 수집 시간과 판정 성립 후 3초 명령 기한은 별개입니다.

로컬 검증: ROI 도형·경계·기본 정사각형 4개, CPU 카메라 런타임 5개, 판정 파이프라인 5개, 카메라 설정 API 9개, 출동 차단 8개 및 카메라·ROI·설정 JavaScript 시험 통과. 출동 시험은 격리 SQLite와 가짜 직렬 장치를 사용했습니다.

Vercel 운영 배포 READY 및 새 ROI 적용 응답을 확인했습니다. 사용자는 웹 새로고침 후 카메라를 다시 연결해야 최신 서버·클라이언트 경로를 사용합니다.
