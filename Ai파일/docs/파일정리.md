## 삭제

- AI 내부의 재생성 가능한 Python·검사 캐시
- 배포 준비본의 `.before-web-configuration` 백업 4개와 사용하지 않는 설정 `.bak`
- `local-model/optimization-backups/`: 최적화 이전 임시 소스 백업
- `edge-vision/README_HANDOFF.md`: 현재 안내서와 겹치는 전달 당시 안내
- `edge-vision/reference/configs/`: 실행·검사에서 사용하지 않는 옛 전체 파이프라인 설정
- 웹 쪽 `scripts/local_ai.py`, `scripts/model_stream.py`, `scripts/prepare-tracking.py`: AI 원본으로 연결만 하던 중복 파일
- 루트 `requirements-local-ai.txt`: AI 패키지 목록으로 연결만 하던 중복 파일

실제 실행 명령과 검사 가져오기는 AI 원본 경로로 고쳤습니다.
배포 준비 도구는 같은 임시 백업을 반복 생성하지 않도록 정리했습니다.

## 보존

- 모델 가중치·어댑터·토크나이저·메타데이터·필수 라이선스
- 원본 AI Git 체크아웃과 Git 이력
- 실제 Modal 배포에 필요한 소스·모델 사본
- 현재 보정·설정 파일, 생성한 인쇄용 마커, 테스트 코드와 잘못된 보정 입력 예시
- 사용 중인 가상환경의 패키지·실행 파일

가중치는 이동 전후 SHA-256 해시로 일치 여부를 확인합니다.
웹 관제 코드와 웹 서버 코드는 각각 `code/`, `backend/`에 유지합니다.
공유 설정 규약과 웹 수신 API까지 AI 폴더로 옮기지는 않습니다.
