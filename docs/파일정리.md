# 파일 정리 내역 · 2026-11-18

## 삭제

- `backend(org)/`: 현재 서버가 사용하지 않는 이전 백엔드 원본
- `dist/`: 현재 화면 원본과 중복되는 오래된 배포 복사본
- `.local-signal-test/`: 별도 로컬 신호 시험용 프로젝트 복사본
- `SIGNAL_TEST.md`: 현재 관제와 다른 예전 로컬 신호 시험 설명서
- `scripts/check_bridge_auth.py`: 일회성 인증·정지 점검 도구
- `scripts/usb_low_speed_test.py`: 일회성 USB 추진·조향 시험 도구
- AI·가상환경 외부의 Python 캐시, pytest 캐시, macOS `.DS_Store`

`public/`의 예전 생성물도 지웠습니다. 다음 빌드 시 현재 `code/`에서 다시 만들어집니다.
Git으로 관리하던 이전 파일은 과거 커밋에서 확인할 수 있습니다.
삭제한 로컬 복사본·캐시는 Git으로 복구되는 자료가 아닙니다.

이동한 브릿지의 명령 처리·시간 제한·정지 동작은 변경하지 않았습니다.
