# 보드 연결 안내

이 문서의 모든 명령은 저장소 최상위 폴더에서 실행합니다.
관제 웹의 신호 조작부는 카메라 미연결 시 보드 상태창 아래에,
카메라 연결 시 대시보드와 이벤트 타임라인 사이에 표시됩니다.

## 1. 필요한 프로그램 설치

Windows PowerShell:

```powershell
python -m venv .venv-bridge
.\.venv-bridge\Scripts\python.exe -m pip install -r hardware/requirements.txt
```

Mac:

```sh
python3 -m venv .venv-bridge
.venv-bridge/bin/python -m pip install -r hardware/requirements.txt
```

## 2. USB로 연결하는 경우

현재 프로그램은 Windows COM3, 9600bps, 사이트 `chunjeon` 기준입니다.
포트가 다르면 `hardware/bridges/usb_bridge.py`의 실제 포트 설정을 확인하세요.
같은 포트를 사용하는 다른 프로그램은 종료합니다.

```powershell
.\.venv-bridge\Scripts\python.exe hardware/bridges/usb_bridge.py
```

웹 로그인 ID와 비밀번호를 터미널에 입력합니다. 비밀번호는 화면에 표시하거나 저장하지 않습니다.
`BOARD: OK S`, `ARMED`가 나타나면 관제에서 같은 사이트를 선택합니다.

- 신호 패널에서 USB 방식을 선택합니다.
- `모의 익수판정`은 실제 AI 판정과 별개인 명시적 출동 시험입니다.
- AI 자동 출동은 유효한 보정 좌표와 같은 대상의 익수 점수 0.8 이상·연속 15프레임 확정이 필요합니다.
- 서버는 신선한 판정 근거와 브릿지 연결을 확인합니다. 확정 후 명령 발행 기한은 3초입니다.
- 현재 실제 동작은 **추진 10%, 조향 중앙, 최대 0.8초 직진 후 정지**입니다.
- 접근 항법·구조망·자동 복귀·구조 완료는 이 브릿지에서 수행하지 않습니다.
- 한 번의 로컬 준비 세션당 출동은 한 번입니다. 다시 시험하려면 이전 판정이 남지 않도록 새 카메라 세션을 시작하고 브릿지를 다시 준비하세요.

비상정지·카메라 해제·통신 오류·종료 시 정지하며, 별도 감시 루프가 주행 시간을 제한합니다.
웹의 명령 발행 표시와 실제 보드의 수신·이동 확인은 구분됩니다.

## 3. HC-06으로 연결하는 경우

USB 경로와 별개입니다. HC-06을 운영체제에서 페어링하고 실제 송신 포트를 확인합니다.
PIN과 지원 여부, 펌웨어 설정은 사용하는 장치 기준으로 확인하세요.

Mac의 포트 조회 예시:

```sh
.venv-bridge/bin/python hardware/bridges/hc06_bridge.py --list-ports
```

현재 웹 로그인 토큰은 `DG_BRIDGE_TOKEN` 환경변수로 전달합니다. 소스 코드에 쓰지 마세요.

```sh
.venv-bridge/bin/python hardware/bridges/hc06_bridge.py --check-web
.venv-bridge/bin/python hardware/bridges/hc06_bridge.py --port /dev/cu.HC-06-DevB --baud 9600
```

Windows에서는 `.venv-bridge\Scripts\python.exe`와 실제 `COM` 포트를 사용합니다.
`--check-web`은 장치를 열거나 명령을 생성하지 않습니다.

이 브릿지는 `/api/test-control`을 읽습니다. 관제 신호 패널에서 HC-06 모드를 선택하세요.
현재 `RETURN`은 정지로 처리되며 좌표 기반 자동 복귀가 아닙니다.
추진·구조망 명령과 각도는 해당 보드 펌웨어에 맞는지 확인해야 합니다.

## 개발 참고
