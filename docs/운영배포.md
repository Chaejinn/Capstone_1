# 웹 실행과 Vercel 배포

## 로컬 웹 실행

저장소 최상위 폴더에서 실행합니다.

```sh
python -m pip install -r requirements.txt
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

- 웹: http://127.0.0.1:8000
- API 문서: http://127.0.0.1:8000/api/docs
- 상태 확인: `/api/health`

`app.py` → `backend/app/main.py`가 통합 서버 진입점입니다.
화면은 `code/`, 인증·사이트·AI 프록시·설정은 `backend/platform/`에 있습니다.
브라우저 카메라는 별도 OpenCV 설치 없이 사용하며, 서버 PC의 카메라를 직접 열 때에는 OpenCV가 추가로 필요합니다.

## 환경변수

실제 값은 환경변수로 설정합니다. 비밀번호·토큰·DB 연결 문자열을 문서나 Git에 저장하지 않습니다.

| 항목 | 용도 |
| --- | --- |
| `DG_DATABASE_URL` / `POSTGRES_URL` / `DATABASE_URL` | 순서대로 확인하는 DB 연결 주소 |
| `DG_SECRET_KEY` | 로그인 토큰 서명 키 |
| `DG_ADMIN_ID`, `DG_ADMIN_PW` | 새 DB의 최초 관리자 생성 |
| AI 서버 관련 설정 | [기존 모델 연결 기록](../Ai파일/docs/모델연결.md)의 현재 운영 설정 참조 |

Vercel은 영구 PostgreSQL DB와 별도 서명 키가 필요합니다. 로컬 SQLite 파일을 업로드하지 않습니다.
브라우저 카메라 분석은 Vercel의 `/api/vision/streams` 인증 프록시를 거쳐 별도 Modal 서버에서 처리합니다.
웹 배포만으로 모델 파일이나 Modal 서비스가 배포되는 것은 아닙니다.

## Vercel 배포

`code/` 폴더만 올리지 말고 저장소 최상위 폴더를 프로젝트 루트로 사용합니다.

```sh
vercel login
vercel link
vercel --prod
```

- 설정: `vercel.json`, `.vercelignore`
- 빌드: `python scripts/build-vercel.py`
- 생성 폴더: `public/` — 자동 생성물이므로 직접 수정하지 않습니다.
- 함수 리전: `sin1`
- 운영 주소: https://drown-guardian.vercel.app

`.vercelignore`는 AI 원본·로컬 모델, 가상환경, 보드 PC 프로그램, 테스트·설명서를 웹 배포에서 제외합니다.
관제·인증·카메라 API에 필요한 `backend/`와 `code/`는 포함합니다.
로컬 장치·장시간 WebSocket 제어 경로와 Vercel 서버리스 API는 구분해서 사용합니다.

## 확인

배포가 준비 완료된 뒤 `/api/health`, 로그인 화면, 관제 화면을 확인합니다.
카메라·AI·실물 보드는 각각 연결 상태와 동작을 따로 검증합니다.
코드를 수정한 뒤 GitHub 자동 동기화를 사용 중이라면 해당 변경이 커밋·푸시될 수 있습니다.
작업 중인 내용을 배포하고 싶지 않다면 `main` 이외의 작업 브랜치를 사용하세요.
